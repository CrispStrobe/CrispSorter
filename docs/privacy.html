CrispSorter Privacy Policy

Last updated: July 10, 2026

Summary

CrispSorter does not collect, store, or transmit any personal data. All document processing, search indexing, OCR, and AI inference run entirely on your device.

Data Processing

CrispSorter is an offline-first document organizer. Your documents, search indexes, metadata, and settings are stored locally on your device and are never sent to any server operated by CrispSorter or its developers.

Optional Cloud Features

CrispSorter offers optional integrations with third-party services that you may choose to configure:

  • Cloud LLM providers (OpenAI, Anthropic, Groq, etc.): If you configure an API key and use the translation or chat features, document text is sent to the provider you selected. These providers have their own privacy policies.
  • Cloud storage (Google Drive, OneDrive, WebDAV, Internxt, Filen): If you connect a cloud drive, CrispSorter accesses files in that drive using credentials you provide. No data is shared with CrispSorter's developers.
  • Cloud backup sync: If you configure the optional cloud-backup feature with your own server, document metadata and search indexes are synced to that server. You control the server.

None of these features activate without your explicit configuration. By default, CrispSorter operates entirely offline.

Analytics and Telemetry

CrispSorter contains no analytics, telemetry, crash reporting, or tracking of any kind. No usage data is collected or transmitted.

Credentials

API keys and passwords you enter are stored in your operating system's secure credential store (macOS Keychain, Windows Credential Manager, Linux Secret Service, or iOS Keychain). They are never stored in plaintext or transmitted to CrispSorter's developers.

Children's Privacy

CrispSorter does not knowingly collect any information from children under the age of 13.

Changes
