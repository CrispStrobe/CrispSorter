`original-preflight.json` is the reviewed original Windows retry preflight,
retained before package verification failed. It binds original app/source inputs
and the separate original build-workflow source/tree. No numeric hosted run,
job, draft identifiers, credentials or compiled-package qualification are added.
The corresponding exact ZIP is pinned separately in
`scripts/windows-retained-package-lock.json`; this fixture is not a completed
post-build release receipt or an independent compiled-source attestation.
